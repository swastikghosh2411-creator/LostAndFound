How it works

  1. Create an account

    Sign up with your email so posts are tied to a real person.

  2. Post the item

    Add a photo, a short description, where it happened and when. Finders can say where the item is being kept.

  3. Get notified

    When a lost post and a found post look like the same item, the owner is notified and can check the details.

  4. Prove it is yours

    The finder can set a question only the owner would know. Contact details are shared after it is answered.
